# Ops, Gates and READMEs Implementation Plan

**Goal:** Give the six human gates (G1–G6) their tools and their records, and write the two judge-facing READMEs.
- The tools: the day-1 smoke checks, the wallet operations (demo-wallet key, buys, router approvals, a funding check), the receipt-seed export and verify, and the DevEx log with its measured section.
- The gates are the paused, human-run checkpoints: smoke checks, funding, both Render deploys, ERC-8004 registration, the live rehearsal, and the export of real receipts.

**Architecture:**
- `scripts/lib/*` holds pure or injectable logic that is unit-tested with fakes and the real captured 402 fixtures.
- `scripts/smoke.ts` and `scripts/ops.ts` are thin CLIs that build real clients from `.env` and print one line per result. Every check that a gate depends on ends with a `verify` command that prints `PASS` or `FAIL`.
- Smoke results are committed as JSON under `docs/gates/smoke/`. Receipts proven on-chain are committed into the seed files, which the hosted checkout re-verifies at boot.

**Tech Stack:** Node.js >= 22.12 (`process.loadEnvFile`), TypeScript ~5.9.3, tsx ^4.23.15, viem ^2.57.3, vitest ^3.2.7, the Binance Web3 API clients from `@sharepay/core`, the buyer engine from `@sharepay/buyer`, the Agentic Wallet CLI `baw` 1.10.0, and BNB Agent Studio CLI `@bnbagent/studio-cli` 0.0.14 (`npx bag`).

**Source spec:** docs/superpowers/specs/2026-10-06-sharepay-design.md (§8 ops, gates and hosting; §9 DevEx log)

**Conventions for every task in this plan:**
- Scripts run from the repo root via the root npm scripts `smoke`, `ops` and `devex:summary` (tsx).
- Scripts load `.env` themselves, print key-free output, and never print a private key or an API secret.
- Code-task gates use `npm run check -- <test file>`, which runs the whole-repo `tsc` and then the vitest file.
- Human-gate tasks (Tasks 7–12) are paused by the orchestrator for a human. Their gate is a `verify` command over the records they produce.
- README gates are the kit's PowerShell conformance check, run in PowerShell.

```ts
import { existsSync, readFileSync } from "node:fs";
import { dirname, join, resolve } from "node:path";

export function repoRoot(start: string = process.cwd()): string {
  let dir = resolve(start);
  for (;;) {
    const candidate = join(dir, "package.json");
    if (existsSync(candidate)) {
      try {
        const pkg = JSON.parse(readFileSync(candidate, "utf8")) as { name?: string };
        if (pkg.name === "sharepay") return dir;
      } catch {
        // unreadable package.json: keep walking up
      }
    }
    const parent = dirname(dir);
    if (parent === dir) return resolve(start);
    dir = parent;
  }
}

export function loadDotEnv(root: string): boolean {
  const path = join(root, ".env");
  if (!existsSync(path)) return false;
  process.loadEnvFile(path);
  return true;
}

export interface ParsedArgs {
  command: string | null;
  positionals: string[];
  flags: Record<string, string | true>;
}

export function parseArgs(argv: string[], booleanFlags: ReadonlySet<string> = new Set()): ParsedArgs {
  const positionals: string[] = [];
  const flags: Record<string, string | true> = {};
  for (let i = 0; i < argv.length; i += 1) {
    const arg = argv[i] ?? "";
    if (!arg.startsWith("--")) {
      positionals.push(arg);
      continue;
    }
    const body = arg.slice(2);
    const eq = body.indexOf("=");
    if (eq >= 0) {
      flags[body.slice(0, eq)] = body.slice(eq + 1);
    } else if (booleanFlags.has(body) || i + 1 >= argv.length || (argv[i + 1] ?? "").startsWith("--")) {
      flags[body] = true;
    } else {
      flags[body] = argv[i + 1] ?? "";
      i += 1;
    }
  }
  return { command: positionals[0] ?? null, positionals: positionals.slice(1), flags };
}

export function envValue(text: string, key: string): string | null {
  for (const line of text.split(/\r?\n/)) {
    const match = line.match(/^\s*([A-Za-z_][A-Za-z0-9_]*)\s*=(.*)$/);
    if (match && match[1] === key) return (match[2] ?? "").trim().replace(/^(['"])(.*)\1$/, "$2");
  }
  return null;
}

export function upsertEnvLine(text: string, key: string, value: string): string {
  const lines = text.split("\n");
  const index = lines.findIndex((line) => new RegExp(`^\\s*${key}\\s*=`).test(line));
  if (index >= 0) {
    lines[index] = `${key}=${value}`;
  } else if (lines.length > 1 && lines[lines.length - 1] === "") {
    lines.splice(lines.length - 1, 0, `${key}=${value}`);
  } else if (lines.length === 1 && lines[0] === "") {
    lines[0] = `${key}=${value}`;
  } else {
    lines.push(`${key}=${value}`);
  }
  return lines.join("\n");
}
```

```ts
import type { EndpointSummary } from "@sharepay/core/devex";

export const MEASURED_START = "<!-- devex:measured:start -->";
export const MEASURED_END = "<!-- devex:measured:end -->";

function cell(value: string): string {
  return value.replace(/\|/g, "\\|").replace(/\r?\n/g, " ");
}

export function renderMeasured(summaries: EndpointSummary[], generatedAt: string, totalEvents: number): string {
  if (totalEvents === 0) {
    return "_No API calls recorded yet. Run the checkout or the merchant with `DEVEX_EVENTS_PATH=devex/events.jsonl`, then `npm run devex:summary`._";
  }
  const lines = [
    `_Generated by \`npm run devex:summary\` at ${generatedAt} from ${totalEvents} API calls._`,
    "",
    "| Endpoint | Calls | Errors | p50 ms | p95 ms |",
    "|---|---|---|---|---|",
    ...summaries.map((s) => `| \`${cell(s.path)}\` | ${s.calls} | ${s.errors} | ${s.p50Ms} | ${s.p95Ms} |`),
  ];
  const codes = summaries.flatMap((s) => s.codes.filter((c) => c.code !== "0").map((c) => ({ path: s.path, ...c })));
  if (codes.length > 0) {
    lines.push("", "| Endpoint | Code | Count | Message |", "|---|---|---|---|");
    for (const c of codes) lines.push(`| \`${cell(c.path)}\` | ${cell(c.code)} | ${c.count} | ${cell(c.msg)} |`);
  }
  return lines.join("\n");
}

export function replaceMeasured(doc: string, section: string): string {
  const start = doc.indexOf(MEASURED_START);
  const end = doc.indexOf(MEASURED_END);
  if (start < 0 || end < start) throw new Error("DEVEX_LOG.md is missing the devex:measured markers");
  return `${doc.slice(0, start + MEASURED_START.length)}\n${section}\n${doc.slice(end)}`;
}
```

```ts
export function smokePath(root: string, id: SmokeId): string {
  return join(root, "docs", "gates", "smoke", `${id}.json`);

export function writeSmoke(root: string, record: SmokeRecord): string {
  const path = smokePath(root, record.id);
  mkdirSync(dirname(path), { recursive: true });
  writeFileSync(path, `${JSON.stringify(record, null, 2)}\n`, "utf8");
  return path;
}

export function readSmoke(root: string, id: SmokeId): SmokeRecord | null {
  const path = smokePath(root, id);
  if (!existsSync(path)) return null;
  try {
    return JSON.parse(readFileSync(path, "utf8")) as SmokeRecord;
  } catch {
    return null;
  }
}

export function verifySmoke(root: string, ids: SmokeId[]): { ok: boolean; lines: string[] } {
  const lines: string[] = [];
  let ok = ids.length > 0;
  for (const id of ids) {
    const record = readSmoke(root, id);
    if (!record) {
      ok = false;
      lines.push(`${id}: not recorded (run npm run smoke -- ${id})`);
      continue;
    }
    if (!record.ok) ok = false;
    lines.push(`${id}: ${record.ok ? "OK" : "FAIL"} at ${record.at}: ${record.summary}`);
  }
  return { ok, lines };
}

}

export async function checkAwPreview(fetchImpl: typeof fetch, baw: BawClient, merchantUrl: string, at: string): Promise<SmokeRecord> {

    const state = option ? `${option.status}${option.reasons.length > 0 ? ` (${option.reasons.join(", ")})` : ""}` : "no matching option";

      at,
      ok: true,

export async function checkOndo(rwa: RwaApi, trading: TradingApi, wallet: Address, at: string): Promise<SmokeRecord> {
  const stock = getStock("NVDAon");
  try {
    const tokens = await rwa.tokens({ platformId: "ondo" });
    const token = tokens.find((t) => t.tokenContractAddress.toLowerCase() === stock.address);
    if (!token?.tokenPrice) throw new Error("NVDAon has no live token price");
    const detail: Record<string, unknown> = { tokenPrice: token.tokenPrice, status: token.statusInfo ?? null };
    const parts: string[] = [];
    for (const usd of ["0.05", "10"]) {
      const { sellAmount } = estimateSale({ priceAtomic: toUnits(usd, 18), tokenPriceUsd: token.tokenPrice, sharesPerToken: ONE });
      const outcome = await probeRoute(trading, { stock: stock.address, payAsset: getStable("U").address, sellAmount, wallet });
      if (outcome.kind === "swap") {

        parts.push(`$${usd}: SWAP route (${outcome.legs.length} leg${outcome.legs.length === 1 ? "" : "s"})`);

        detail[`usd_${usd}`] = { kind: outcome.kind, code: outcome.code, message: outcome.message, minUsd: outcome.minUsd };
        parts.push(`$${usd}: ${outcome.kind}${outcome.minUsd ? ` (min $${outcome.minUsd})` : ""}`);
```

```ts
function normalizeKey(raw: string): Hex {
  return (raw.startsWith("0x") ? raw : `0x${raw}`) as Hex;
}

export function newBurner(root: string, generate: () => Hex = generatePrivateKey): { address: Address; created: boolean } {
  const envPath = join(root, ".env");
  const examplePath = join(root, ".env.example");
  const text = existsSync(envPath) ? readFileSync(envPath, "utf8") : existsSync(examplePath) ? readFileSync(examplePath, "utf8") : "";
  const existing = envValue(text, "BUYER_PRIVATE_KEY");
  if (existing) return { address: privateKeyToAccount(normalizeKey(existing)).address, created: false };
  const key = generate();
  writeFileSync(envPath, upsertEnvLine(text, "BUYER_PRIVATE_KEY", key), "utf8");
  return { address: privateKeyToAccount(key).address, created: true };
}

export interface WalletReadDeps {
  rwa: RwaApi;
  walletApi: WalletApi;

  nowMs: () => number;

export async function describeBalances(deps: WalletReadDeps, owner: Address): Promise<string[]> {
  const snapshot = await loadMarketSnapshot(deps.rwa, deps.nowMs());
  const holdings = await loadHoldings({ wallet: deps.walletApi, chain: deps.chain }, owner, snapshot);
  const lines = [`Wallet ${owner}`];
  for (const holding of holdings) {
    const shares = formatSignificant(sharesFromTokens(holding.balance, holding.sharesPerToken), 18, 4);
    const value = holding.priceUsd ? ` (~$${usdValue(holding.balance, holding.priceUsd)})` : "";
    lines.push(`  ${holding.stock.name} (${holding.stock.symbol}): ${shares} shares${value}`);
  }
  if (holdings.length === 0) lines.push("  no tokenized stocks");
  for (const stable of STABLES) lines.push(`  ${stable.symbol}: ${formatAmount(await deps.chain.balanceOf(stable.address, owner), 18, 6)}`);
  lines.push(`  BNB: ${formatAmount(await deps.chain.nativeBalance(owner), 18, 6)}`);

export async function planBuy(trading: TradingApi, owner: Address, stockSymbol: string, usdt: string): Promise<SalePlan> {
  const stock = getStock(stockSymbol);
  const amount = toUnits(usdt, 18);
  const outcome = await probeRoute(trading, { stock: getStable("USDT").address, payAsset: stock.address, sellAmount: amount, wallet: owner });
  if (outcome.kind !== "swap") throw new Error(`no SWAP route to buy ${stock.symbol}: ${outcome.message}`);
  return {
    stock,
    payAsset: stock.address,
    priceAtomic: (outcome.expectedOut * 97n) / 100n,
    legs: outcome.legs,
    sellAmount: amount,
    expectedOut: outcome.expectedOut,
    priceImpactPercent: outcome.priceImpactPercent,
  };
}

export async function saleRoute(trading: TradingApi, stock: Address, owner: Address, balance: bigint): Promise<{ spender: Address; vendor: string | undefined }> {
  const amount = balance >= 10n ? balance / 10n : 10n ** 14n;
  const outcome = await probeRoute(trading, { stock, payAsset: getStable("U").address, sellAmount: amount, wallet: owner });
  if (outcome.kind !== "swap") return { spender: AGGREGATION_ROUTER, vendor: undefined };
  const first = outcome.legs[0];
  return { spender: (first?.route.approveTarget ?? AGGREGATION_ROUTER) as Address, vendor: first?.route.vendorName ?? undefined };
}

export interface ApproveDeps {
  trading: TradingApi;
  tx: TransactionApi;
  chain: ChainReader;
  signer: TxSigner;
  receiptTimeoutMs: number;
}

export async function approveForSale(deps: ApproveDeps, stockSymbol: string): Promise<{ spender: Address; txHash: Hex | null }> {
  const stock = getStock(stockSymbol);
  const owner = deps.signer.address;
  const balance = await deps.chain.balanceOf(stock.address, owner);
  const { spender, vendor } = await saleRoute(deps.trading, stock.address, owner, balance);
  if ((await deps.chain.allowance(stock.address, owner, spender)) >= MAX_UINT256 / 2n) return { spender, txHash: null };
  const approve = await deps.trading.approveTransaction({ tokenContractAddress: stock.address, approveAmount: MAX_UINT256, vendor });
  if (!sameAddress(approve.dexContractAddress, spender)) {
    throw new Error(`approve spender ${approve.dexContractAddress} does not match the sale route's spender ${spender}`);
  }
  const prepared = { to: stock.address, data: approve.data as Hex, value: 0n };
  const simulation = await simulatePrepared(deps.tx, owner, prepared);
  if (!simulation.ok) throw new Error(`approve simulation failed: ${simulation.failReason ?? simulation.status}`);
  const { txHash } = await sendPrepared({ tx: deps.tx, chain: deps.chain, signer: deps.signer }, prepared, {
    mevProtection: false,
    receiptTimeoutMs: deps.receiptTimeoutMs,
    gasFallback: 80_000n,
  });
  return { spender, txHash };
}

export async function verifyFunding(
  deps: { trading: TradingApi; chain: ChainReader },
  targets: FundingTarget[],
  options: { stock: string; minBnbWei: bigint },
): Promise<{ ok: boolean; lines: string[] }> {
  const stock = getStock(options.stock);
  const lines: string[] = [];
  let ok = targets.length > 0;
  for (const target of targets) {
    const parts: string[] = [];
    const problems: string[] = [];
    if (target.requireStock) {
      const balance = await deps.chain.balanceOf(stock.address, target.address);
      parts.push(`${stock.symbol} ${formatAmount(balance, 18, 6)}`);
      if (balance === 0n) problems.push(`holds no ${stock.symbol}`);
      if (target.requireApproval && balance > 0n) {
        const { spender } = await saleRoute(deps.trading, stock.address, target.address, balance);
        const approved = (await deps.chain.allowance(stock.address, target.address, spender)) >= balance;
        parts.push(`${approved ? "approved" : "not approved"} for ${spender}`);
        if (!approved) problems.push("run npm run ops -- approve");
      }
    }
```

```ts
import { existsSync, readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import type { ChainReader } from "@sharepay/core/chain/rpc";
import type { ItemId, MerchantActivity, Receipt } from "@sharepay/core/dto";
import type { Hex } from "viem";

export const RECEIPTS_SEED = "data/receipts.seed.json";
export const ACTIVITY_SEED = "data/merchant-activity.seed.json";
const ITEM_IDS: readonly ItemId[] = ["sharepay-nvda-report", "bnb-stock-analyst-nvda", "cmc-nvda-dossier"];

export interface SeedDeps {
  fetchImpl: typeof fetch;
  verifyReceipt: (receipt: Receipt) => Promise<boolean>;
  verifyTx: (hash: string) => Promise<boolean>;
}

export function txVerifier(chain: Pick<ChainReader, "waitForReceipt">): (hash: string) => Promise<boolean> {
  return async (hash) => {
    if (!/^0x[0-9a-fA-F]{64}$/.test(hash)) return false;
    try {
      return (await chain.waitForReceipt(hash as Hex, 10_000)).status === "success";
    } catch {
      return false;
    }
  };
}

function readList<T>(path: string): T[] {
  if (!existsSync(path)) return [];
  try {
    const parsed = JSON.parse(readFileSync(path, "utf8")) as unknown;
    return Array.isArray(parsed) ? (parsed as T[]) : [];
  } catch {
    return [];
  }
}

function mergeById<T extends { id: string }>(existing: T[], fresh: T[]): T[] {
  const byId = new Map(existing.map((item) => [item.id, item]));
  for (const item of fresh) byId.set(item.id, item);
  return [...byId.values()];
}

async function allVerified(verifyTx: (hash: string) => Promise<boolean>, hashes: string[]): Promise<boolean> {
  if (hashes.length === 0) return false;
  for (const hash of hashes) {
    if (!(await verifyTx(hash).catch(() => false))) return false;
  }
  return true;
}

async function getJson(fetchImpl: typeof fetch, url: string): Promise<unknown> {
  const response = await fetchImpl(url, { headers: { Accept: "application/json" }, signal: AbortSignal.timeout(120_000) });
  if (!response.ok) throw new Error(`${url} answered HTTP ${response.status}`);
  return response.json();
}

export async function exportSeeds(
  deps: SeedDeps,
  root: string,
  urls: { checkoutUrl: string; merchantUrl: string },
): Promise<{ receipts: number; activity: number; skipped: string[] }> {
  const skipped: string[] = [];
  const ledger = (await getJson(deps.fetchImpl, `${urls.checkoutUrl.replace(/\/+$/, "")}/api/ledger`)) as { receipts?: Receipt[] };
  const freshReceipts: Receipt[] = [];
  for (const receipt of ledger.receipts ?? []) {
    if (await deps.verifyReceipt(receipt).catch(() => false)) freshReceipts.push(receipt);
    else skipped.push(`receipt ${receipt.id}`);
  }
  const receiptsPath = join(root, RECEIPTS_SEED);
  const receipts = mergeById(readList<Receipt>(receiptsPath), freshReceipts).sort((a, b) => a.createdAt.localeCompare(b.createdAt));
  writeFileSync(receiptsPath, `${JSON.stringify(receipts, null, 2)}\n`, "utf8");

  const feed = (await getJson(deps.fetchImpl, `${urls.merchantUrl.replace(/\/+$/, "")}/sharepay/activity`)) as { items?: MerchantActivity[] };
  const freshActivity: MerchantActivity[] = [];
  for (const item of feed.items ?? []) {
    if (await allVerified(deps.verifyTx, item.txHashes)) freshActivity.push(item);
    else skipped.push(`activity ${item.id}`);
  }
  const activityPath = join(root, ACTIVITY_SEED);
  const activity = mergeById(readList<MerchantActivity>(activityPath), freshActivity).sort((a, b) => a.at.localeCompare(b.at));
  writeFileSync(activityPath, `${JSON.stringify(activity, null, 2)}\n`, "utf8");
  return { receipts: receipts.length, activity: activity.length, skipped };
}

function plural(count: number, word: string): string {
  return `${count} ${word}${count === 1 ? "" : "s"}`;
}

export async function verifySeeds(deps: Pick<SeedDeps, "verifyReceipt" | "verifyTx">, root: string): Promise<{ ok: boolean; lines: string[] }> {
  const lines: string[] = [];
  let ok = true;
  const verified: Receipt[] = [];
  for (const receipt of readList<Receipt>(join(root, RECEIPTS_SEED))) {
    if (await deps.verifyReceipt(receipt).catch(() => false)) verified.push(receipt);
    else {
      ok = false;
      lines.push(`receipt ${receipt.id}: its transactions are not confirmed on-chain`);
    }
  }
  for (const itemId of ITEM_IDS) {
    const count = verified.filter((r) => r.itemId === itemId).length;
    if (count === 0) ok = false;
    lines.push(`${itemId}: ${plural(count, "verified receipt")}`);
  }
  let settlements = 0;
  let sweeps = 0;
  for (const entry of readList<MerchantActivity>(join(root, ACTIVITY_SEED))) {
    if (entry.kind === "sweep_skipped") continue;
    if (!(await allVerified(deps.verifyTx, entry.txHashes))) {
      ok = false;
      lines.push(`merchant ${entry.kind} ${entry.id}: its transactions are not confirmed on-chain`);
      continue;
    }
    if (entry.kind === "settlement") settlements += 1;
    else sweeps += 1;
  }
  if (settlements === 0 || sweeps === 0) ok = false;
  lines.push(`merchant activity: ${plural(settlements, "verified settlement")}, ${plural(sweeps, "verified reinvest sweep")}`);
  return { ok, lines };
}
```

````markdown
## How it works

**One checkout, eight steps.** The progress view shows each step with its BscScan links.

| # | Step | What happens |
|---|---|---|
| 1 | Price checked | The merchant answers HTTP 402 with an x402 v2 `exact` requirement: an EIP-3009 transfer of U (or USD1) on BSC. |
| 2 | Shares priced | The planner sizes the sale from the RWA Data API price plus a buffer, then re-quotes it through the Trading API. SWAP routes only, with a LiquidMesh fallback and a two-leg route through USDT. |
| 3 | Sale checked | The sale (or the one-time approval) is dry-run with the Transaction API `simulate`. |
| 4 | Shares sold | The demo wallet signs the swap and broadcasts it with MEV protection. The Agentic Wallet sells with `baw market-order swap` instead. |
| 5 | Payment approved | The wallet signs an EIP-3009 `transferWithAuthorization`. The Agentic Wallet uses `baw x402-payment preview/sign` instead. |
| 6 | Merchant paid | The request is replayed with `PAYMENT-SIGNATURE`. Our merchant verifies 14 rules, simulates the settlement and broadcasts it from its BNB Agent Studio wallet. Third-party merchants settle through Binance's b402 facilitator. |
| 7 | Report delivered | Delivery is instant for our report. The stock analyst runs as a polled async job. CMC answers with a server-sent-events reply. |
| 8 | Merchant reinvested in S&P 500 shares | Our merchant's sweeper swaps what it earned into SPYB and records the transaction. |
````
